# Phase 3 Plan: Structured Scientific Fact Extraction

## Objective

Build a tested spaCy + SciBERT pipeline that emits exact, typed evidence
statements from normalized Phase 2 documents and stores them as queryable
PostgreSQL rows linked to the source paper.

## TDD sequence

1. **Schema and sentence rules:** first test canonical types, strong positive
   cues, section priors, multi-label sentences, and representative negatives.
2. **Semantic fallback:** first test injected embeddings, confidence/margin
   rejection, deterministic ties, and lazy reuse of Phase 2’s SciBERT embedder.
3. **Storage:** first test insert/replace/query-by-type, paper foreign keys,
   and duplicate suppression with in-memory SQLite.
4. **Service:** first test traversal of Phase 2 JSON, exact coordinates,
   fallback sentence segmentation, semantic calls only for unmatched sentences,
   idempotent persistence, and corpus-wide extraction.
5. **Phase gate:** run all backend tests, explicit real-SciBERT smoke test,
   Ruff, diff checks, then review data integrity, false-positive boundaries,
   source evidence preservation, and phase-scope/security constraints.

## Done when

Every parsed paper can be processed into zero or more exact evidence rows;
rows are linked to `paper_id`, queryable by the six canonical types, and safe to
replace on re-extraction. Tests demonstrate all six types and end-to-end storage.
