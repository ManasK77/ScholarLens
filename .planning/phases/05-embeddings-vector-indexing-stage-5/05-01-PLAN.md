Requirements: EMBED-01 … EMBED-04. README §8 Stage 5 / §15 Phase 5.
**Tech is fixed by the spec: SPECTER2 + Qdrant.**

## Starting position

`app/embeddings/indexer.py` **survived** the incomplete upstream push
(PROGRESS.md, 2026-09-06 reconciliation) and is the de-facto contract for this

them work, it does not rewrite them.

## Contracts pinned by surviving code (must not change)

From `indexer.py` / `test_indexing.py`:

- `IndexRecord(record_id, paper_id, text, source_type, fact_id, year, venue,
  section_type, graph_node_id)` — **constructed positionally**, nine fields.
- Attributes read by callers: `.record_id`, `.text`, `.paper_id`,
  `.source_type`, `.graph_node_id`, and `.payload()`.
- `payload()` must carry `paper_id`, `year`, `venue`, `section_type`
  (EMBED-02 filtered search), `graph_node_id` (EMBED-03), `text`, `source_type`,
  `fact_id`. It must **not** contain `id` or `score`: `EvidenceIndex.retrieve`
  splats the payload next to those two keys.
- `source_type` values `"paragraph"`, `"limitation"`, `"future_work"` —
  `gap_points()` filters on exactly the last two, and `"graph"` is reserved by
  `app/interactive/workflow.py` for non-vector evidence.
- `Specter2Encoder` exposes `.dimension: int` and
  `.encode(texts, batch_size) -> sequence of vectors`, positionally. The
  returned sequence must be the **same length as `texts`** — `upsert()` zips
  them with `strict=True`.
- `get_encoder()` is module-level in `app.embeddings.encoder` and is
  monkeypatched by name in `test_indexing.py`; it must stay lazy, so an empty
  index never loads a model.
- `EvidenceIndex.ensure_collection()` keeps its exact current shape — the
  surviving 409-race test drives it with a two-method fake client.

## Model decision — D-05-01 (recorded in PROGRESS.md)

Official SPECTER2 = `allenai/specter2_base` + the `allenai/specter2` proximity
adapter, loaded through AdapterHub's `adapters` package. Checked before adding:
`adapters==1.3.0` declares `transformers~=4.57.6`, and Phase 4 pinned
`transformers>=4.57,<5` with 4.57.6 actually installed — so the official path
costs **no change to the Phase 4 (GLiNER2) dependency set**. Retrieval embeddings
use the `[CLS]` token of `last_hidden_state`, per the model card.

`adapters` is imported lazily inside the loader, never at module import, so it
cannot perturb GLiNER2/transformers for any other phase.

## Tasks (TDD — failing test first for each)

1. **`app/embeddings/schema.py`** — `IndexRecord` (frozen dataclass, positional
   field order above) with `payload()`; validation of `source_type`, non-empty
   `text`, non-negative `paper_id`. `SOURCE_TYPES` / `GAP_SOURCE_TYPES` /
   `PAYLOAD_FIELDS` constants so `indexer.gap_points` and Phase 6 share one
   vocabulary.
2. **`app/embeddings/encoder.py`** — `Specter2Encoder(embed_fn, dimension)`
   with deterministic, order-preserving, bounded batching; `load_specter2()`
   (lazy adapters/transformers/torch import); `get_encoder()` cached per process.
3. **Settings** — `qdrant_collection`, `embedding_model`, `embedding_adapter`,
   `embedding_batch_size`, `embedding_max_tokens`, `embedding_max_chars`,
   `retrieval_top_n`. Bounded (`gt=0`, upper caps) so a bad `.env` cannot make
   the batch job allocate unboundedly or silently index nothing.
4. **Indexer hardening (additive only)** — blank-fact skip in
   `build_index_records`; `check_collection_dimension()` guard in `upsert()`
   so writing 768-d vectors into a differently-shaped existing collection fails
   loudly instead of corrupting it; `ensure_payload_indexes()` for the four
   filterable metadata keys, called once from `index_all` after a non-empty run.
5. **Integration tests** — a real `qdrant_client` local instance (no HTTP mock)
   exercising create → upsert → filtered query → scroll; plus one
   `@pytest.mark.integration` test that loads the real SPECTER2 checkpoint and
   asserts dimension, determinism, and that a related sentence out-ranks an
   unrelated one.
