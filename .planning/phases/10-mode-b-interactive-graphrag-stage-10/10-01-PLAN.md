# Phase 10 Plan — Interactive GraphRAG with LangGraph

## Scope and invariants

- Implement only README Phase 10 / MODEB-01..03.
- Use LangGraph directly; add no LangChain dependency or import.
- Reuse Phase 5 Qdrant evidence, Phase 4 Neo4j paper/entity links, and the
  Phase 9 direct Groq structured-output client.
- Leave Phase 9's single-pass report workflow unchanged.
- Cap a request at three retrieval rounds and one controlled stricter answer
  regeneration. Never return an answer that failed grounding as if it passed.

## TDD sequence

1. **State and schemas** — tests for bounded/trimmed reformulations, answer and
   claim schemas, citation shape, retrieval-round and regeneration counters.
2. **Retrieve** — tests proving Qdrant runs first, Neo4j expands from the
   retrieved paper IDs by one graph hop, candidates are deduplicated, malformed
   evidence is dropped, and an actually empty index exits without an LLM call.
3. **Assess** — tests for configurable minimum relevant chunks and distinct
   papers; weak evidence routes to reformulation and strong evidence to rerank.
4. **Reformulate/retry** — tests for visible trace entries and an absolute
   maximum of three Qdrant retrieval rounds.
5. **Rerank** — tests for cross-encoder ordering, score projection, result caps,
   and lazy model loading.
6. **Generate** — tests that only reranked evidence enters the bounded prompt,
   evidence is explicitly untrusted, and every claim names real evidence IDs.
7. **Grounding/regeneration** — tests for structural citation rejection,
   deterministic citation ordering, LLM verification of the answer and claims,
   one stricter regeneration, and safe failure after that regeneration.
8. **Integration and `/query`** — compile/invoke the real LangGraph with mocked
   Qdrant, Neo4j, reranker, and Groq; exercise authenticated FastAPI success and
   provider/error paths without external calls.

## Verification and review

- Review the final diff for retry termination, unsupported-answer leakage,
